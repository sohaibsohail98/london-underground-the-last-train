# Content

Unreal asset packages. Binary, tracked with Git LFS, never merged by hand.

Layout follows the structure described in `docs/brief-v3-unreal.md` and
`CLAUDE.md`:

```
Content/LastTrain/
  Maps/
  Environment/   Station Platform Concourse Train Props
  Characters/    Zombies Player
  Weapons/
  Gameplay/      Rounds Economy Doors WallBuys Perks LostProperty
  UI/
  Audio/
  VFX/
  Materials/
  Data/          Weapon and station data assets
  Input/         Enhanced Input actions and mapping contexts
```

Record provenance and licence for every imported third party asset in
`Content/ATTRIBUTION.md` at import time.
