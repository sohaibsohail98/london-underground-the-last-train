Task: Phase G1, audio. Read docs/tasks/phase-g-audio-hud-balance.md's G1 section for the design brief (ambience, train hum, original announcements, zombie vocals, weapon audio, interaction stingers, round stingers, "silence is a tool", priority order from docs/brief-v3-unreal.md Part 3 phase 8). Scope, two parts:

1. Source/ changes (the actual gap). Add USoundBase* UPROPERTY hooks (EditDefaultsOnly, BlueprintReadOnly, null until a Blueprint or data asset assigns them, following the exact pattern LTPlayerCharacter.h already uses for its EditDefaultsOnly Enhanced Input actions) to the systems that need audio triggers:
   - ULTWeaponData (Source/LastTrain/Public/Weapons/LTWeaponData.h): fire sound, reload start sound, reload complete sound, empty-magazine dry fire sound, one per weapon since this is a data asset already.
   - ULTWeaponComponent (Source/LastTrain/Public/Weapons/LTWeaponComponent.h): trigger points already exist as clear C++ call sites (FireOnce, StartReload, FinishReload) - do not add new sound properties here if they belong on the data asset instead, add the actual UGameplayStatics::PlaySoundAtLocation or PlaySound2D calls (whichever is more correct for a first person weapon, use your judgement and say which you chose and why) at those call sites, reading the sound from WeaponData.
   - ALTZombieCharacter (Zombies/LTZombieCharacter): idle/aggro/attack/death vocal sound properties, likely per ULTZombieTypeData instance (Zombies/LTZombieTypeData.h) rather than one shared sound, following the same per-type override pattern the file already uses everywhere else (a field that falls through to a sensible default when unset).

   - ALTStationHeat if it has any discrete threshold-crossing event worth a stinger (check the file, do not force one in if there is no natural trigger point).
   - ALTInteractionComponent (Interaction/LTInteractionComponent): a generic interaction stinger, e.g. on a successful Interact_Implementation call, check how the existing prompt delegate is structured and follow the same pattern.
   Every property must default to nullptr and every play call must null check first, exactly like every other optional Blueprint-assigned hook in this codebase already does (see LTPlayerCharacter's Enhanced Input actions for the convention). No Source/ change should assume an asset is assigned; the game must still run silently with nothing wired up, same as it runs today with no animations.
