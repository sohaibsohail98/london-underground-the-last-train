### GPT-6 Astra / Fable trial, in progress, not yet reported back

Two research passes were run on whether GPT-6 Astra (OpenAI's current
flagship, real product, shipped 3 September 2026) could help build this game.
First pass concluded no useful edge; the user pushed back, a deeper pass
found genuine first-party computer-use (screen-vision plus real mouse/
keyboard control, not just MCP calls) with credible evidence of it driving
both Blender and Unreal Engine 5 in the wild, at a real but non-trivial
~25% task failure rate and known mid-session amnesia.

Net conclusion: worth trying as a **secondary** tool for original Blender
asset creation, not a replacement for the Claude Code plus MCP-Unreal
pipeline for actual editor/gameplay work, where typed API calls are more
reliable than screen-mirroring with no video feedback.
