Every file in this folder, and every external URL referenced across the folder,
with source, licence and download status.

**Nothing was downloaded.** Every external image, model and photo is
reference-only: URL recorded, content described, licence noted where visible. No
copyrighted photograph was embedded as a project asset. No open-licence asset
was pulled into the folder because none was needed to make the notes useful, and
the strongest candidates carried CC-BY attribution obligations or TfL trade
dress that argue for fetching them at integration time, not now. When assets are
fetched later, log them per the format at the bottom of this file.

## Format for logging a future download

When an asset is fetched into this folder later, add a row here:

`| filename | what it shows | source URL | licence (must permit redistribution) | date fetched |`

and keep the licence text file next to it (for CC-BY/CC-BY-SA, keep the
attribution string; for OFL fonts, keep OFL.txt).
